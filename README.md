# OpenNeuro

## Prerequisites

- [Bun](https://bun.sh/)
- [uv](https://docs.astral.sh/uv/)
- [Rust](https://rustup.rs/) (for desktop app)

## Development

```sh
bun install
```

### Browser (backend + frontend)

```sh
bun dev
```

### Desktop app (Tauri)

```sh
bun tauri dev
```

## Build

```sh
bun tauri build
```
